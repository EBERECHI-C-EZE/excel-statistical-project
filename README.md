# Comparative Analysis of Students’ Performance in Mathematical Statistics and Applied Statistics

## Project Overview
This study compares students’ performance in Mathematical Statistics and Applied Statistics at Federal Polytechnic Oko, Nigeria. It investigates whether students perform differently in both courses and identifies the factors influencing performance.

## Objectives
- Compare students’ performance in both courses
- Test whether there is a significant difference in scores
- Provide recommendations for improving teaching and learning

## Methods
- Data collected from departmental records & questionnaire
- Analyzed using Microsoft Excel
- Paired Sample t-test conducted to check significance
- Descriptive statistics and charts used

## Key Findings
- Students performed slightly better in Applied Statistics
- However, the difference was **not statistically significant** (p = 0.663)
- Students find Applied Statistics more engaging due to real-life applications
- Mathematical Statistics challenges mainly relate to abstraction and teaching methods

## Files in this Repository

## Tools Used
- Microsoft Excel
- Statistical Reasoning
- Research Design & Analysis

## Conclusion
Both courses are important, but Applied Statistics appears slightly easier for students. Better teaching strategies and practical learning can improve Mathematical Statistics performance.
